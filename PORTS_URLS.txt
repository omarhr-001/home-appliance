┌────────────────────────────────────────────────────────────────────┐
│                         API ENDPOINTS
└────────────────────────────────────────────────────────────────────┘

HEALTH CHECK:
  GET http://localhost:3001/api/health
  
  Réponse:
  {
    "status": "ok",
    "message": "Server is running"
  }

PRODUCTS LIST:
  GET http://localhost:3001/api/products
  
  Réponse:
  [
    {
      "id": 1,
      "name": "Washing Machine",
      "price": 399.99,
      "description": "..."
    },
    ...
  ]

PROXY (Frontend):
  /api/* → http://localhost:3001
  
  Le frontend proxifie automatiquement les appels /api vers le backend

  VITE_API_URL=http://localhost:3001

BACKEND (backend/.env):
  NODE_ENV=development

  FRONTEND_URL=http://localhost:5173

┌────────────────────────────────────────────────────────────────────┐
│                    CHANGER LES PORTS (OPTIONNEL)
└────────────────────────────────────────────────────────────────────┘

Si un port est déjà en utilisation:

CHANGER LE PORT FRONTEND:
  1. Éditer frontend/vite.config.ts
  2. Changer: port: 5173 → port: 5174
  3. Relancer pnpm dev

CHANGER LE PORT BACKEND:
  1. Éditer backend/.env
  2. Changer: PORT=3001 → PORT=3002
  3. Relancer pnpm dev

CHANGER L'URL API (Frontend):
  1. Éditer frontend/.env
  2. Changer: VITE_API_URL=http://localhost:3001
  3. Relancer pnpm dev

┌────────────────────────────────────────────────────────────────────┐
│                    VÉRIFIER QUE TOUT FONCTIONNE

   curl http://localhost:3001/api/health

2. Vérifier le Frontend:

   Doit afficher la page d'accueil

3. Vérifier la Connexion:
   Aller à /products
   
   Doit afficher la liste des produits (appel API)
