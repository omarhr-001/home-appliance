Bienvenue dans votre nouveau Home Appliance Store - simplifié et fonctionnel!

================================================================================
                         DÉMARRAGE EN 3 ÉTAPES
================================================================================

1. Installer les dépendances:
   pnpm install

2. Lancer le projet:
   pnpm dev

3. Accéder à l'application:
   Frontend: http://localhost:5173
   Backend:  http://localhost:3001

C'est tout! 🚀

================================================================================
                       FICHIERS CLÉS À CONNAÎTRE
================================================================================

Frontend (React):
- frontend/src/App.tsx          → Routing principal
- frontend/src/pages/            → Pages (Home, Products, etc.)
- frontend/src/components/       → Composants réutilisables
- frontend/.env                  → Variables d'environnement

Backend (Express):
- backend/src/index.ts          → Serveur Express + routes
- backend/.env                   → Configuration serveur

Configuration:
- package.json                   → Scripts pnpm
- pnpm-workspace.yaml           → Configuration workspace

================================================================================
                           COMMANDES UTILES
================================================================================

# Démarrage développement (les deux services)
pnpm dev

# Build production
pnpm build

# Frontend uniquement
cd frontend && pnpm dev

# Backend uniquement
cd backend && pnpm dev

# Vérifier les types TypeScript
pnpm typecheck

# Ajouter une dépendance
cd frontend   # ou cd backend
pnpm add <package>

================================================================================
                        EN CAS DE PROBLÈME
================================================================================

Port déjà en utilisation?
→ Modifier PORT dans backend/.env

Erreurs de dépendances?
→ Supprimer node_modules et relancer pnpm install

Problèmes de démarrage?
→ Vérifier que Node.js 18+ et pnpm sont installés

Toujours bloqué?
→ Consulter README_NEW.md ou PROJECT_STRUCTURE.md
